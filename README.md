# 💬 Веб-приложение «Чат» (Messenger)

> **Статус проекта:** В разработке

## 📖 Описание проекта
Это Single Page Application (SPA), представляющее собой мессенджер для обмена сообщениями

### 🛠 Технологический стек

* **HTML5 / SCSS** — семантическая верстка и стилизация.
* **JavaScript (ES6+)** — логика приложения.
* **Handlebars** — шаблонизация компонентов.
* **Vite** — сборка проекта.
* **TypeScript** - типизация
* **Eslint,stylelint** - линтинг

## 🚀 Инструкция по запуску
Для работы проекта требуется **Node.js** (версии 22+).

Запуск сервера разработки
```bash
npm run start
```

Сборка проекта
```bash
npm run build
```

Проверка типов
```bash
npm run prebuild
```

Линтер
```bash
npm run lint
```

Линтер стилей
```bash
npm run stylelint
```
